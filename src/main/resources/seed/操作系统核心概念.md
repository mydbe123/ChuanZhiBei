# 操作系统核心概念

## 进程与线程
进程是资源分配的基本单位，拥有独立的地址空间；线程是 CPU 调度的基本单位，同一进程内的线程共享地址空间与文件描述符，但各自拥有独立的栈和寄存器上下文。
进程状态机包含新建、就绪、运行、阻塞、终止五种状态。就绪到运行由调度器决定，运行到阻塞由进程主动发起 I/O 或等待资源触发。

进程间通信（IPC）方式：
- 管道（pipe）与命名管道（FIFO）：半双工，适合父子进程。
- 消息队列：有内核维护的消息链表，可随机读取。
- 共享内存：最快的 IPC 方式，需要配合同步机制。
- 信号量：用于同步与互斥。
- 套接字（socket）：可跨主机通信。

## 线程同步
- 互斥锁（mutex）：保证临界区互斥访问。
- 信号量（semaphore）：P/V 操作，可用于计数型同步。
- 条件变量：配合互斥锁实现「等待-通知」。
- 读写锁：读读并发、读写互斥、写写互斥。
死锁的四个必要条件：互斥、请求与保持、不可剥夺、循环等待。破坏任一条件即可预防死锁；也可通过资源有序分配法避免。

## CPU 调度算法
- 先来先服务（FCFS）：非抢占，简单但平均等待时间长。
- 短作业优先（SJF）：平均等待时间最短，但可能导致长作业饥饿。
- 时间片轮转（RR）：抢占式，适合分时系统，时间片过小导致上下文切换开销大。
- 优先级调度：可分为抢占式与非抢占式，存在低优先级饥饿问题，可用老化（aging）缓解。
- 多级反馈队列（MLFQ）：综合时间片轮转与优先级，是目前通用操作系统常用的调度策略。

## 内存管理
- 分页：把逻辑地址空间划分为固定大小的页，物理内存划分为同样大小的页框，通过页表映射，消除外部碎片。
- 分段：按程序的逻辑结构划分，便于共享与保护，但会产生外部碎片。
- 段页式：先分段再分页，兼顾两者的优点。
- 虚拟内存：基于局部性原理，只把当前需要的页面装入内存，缺页时触发缺页中断进行置换。
- 页面置换算法：FIFO（可能出现 Belady 异常）、LRU（最近最久未使用）、Clock（近似 LRU）、OPT（理论最优，用作基准）。
- 抖动（thrashing）：进程频繁缺页导致 CPU 利用率骤降，可通过工作集模型控制驻留集大小。

## 文件系统
- 文件分配方式：连续分配、链式分配、索引分配。索引分配通过索引块记录数据块地址，支持随机访问。
- inode 记录文件的元数据（权限、大小、时间戳、数据块指针），文件名与 inode 通过目录项关联。
- 空闲空间管理：位图、空闲链表、成组链接法。
- 日志文件系统（journaling）先写日志再更新数据，保证崩溃后的一致性。

## I/O 与零拷贝
- 五种 I/O 模型：阻塞 I/O、非阻塞 I/O、I/O 多路复用（select/poll/epoll）、信号驱动 I/O、异步 I/O。
- epoll 采用事件就绪通知，避免了 select 的轮询与文件描述符上限问题，适合高并发服务器。
- 零拷贝技术（sendfile、mmap + write）减少用户态与内核态之间的数据拷贝次数。

## 经典同步问题
- 生产者-消费者问题：用信号量 empty、full 与互斥量 mutex 协作。
- 读者-写者问题：读者优先或写者优先两种策略。
- 哲学家进餐问题：可通过限制同时取筷人数、奇偶编号不同顺序取筷来避免死锁。
